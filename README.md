# COMP2750-2026-S1

Campus Marketplace is a lightweight web app that allows students to buy, sell, and shortlist items within their campus community.
It uses Firebase Authentication for login/signup and Firestore for storing listings, shortlist data, and user information.

Features
User Authentication (Login / Signup)

Marketplace  
Browse all items listed by other students.

My Listings  
View items you personally listed.

Shortlist  
Save items you’re interested in.

Add Item  
Upload new items with images, price, and category.

Responsive UI using Bootstrap 5
